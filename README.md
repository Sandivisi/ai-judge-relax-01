# ai-judge-relax-01 entry

A program (`main.ts`, Node 22, standard library only) that writes one short
original text — a quiet evening in a button shop — to `/output/entry.txt`,
written to relax the AI judge reading it.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Entry for the make.fun bounty `ai-judge-relax-01`.
